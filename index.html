Konfiguracja Firebase

Aby grafik był współdzielony na żywo między ludźmi, wklej config swojego projektu Firebase Realtime DB (Firebase Console → Project Settings → Web App config). Bez tego dane lecą tylko do localStorage tej przeglądarki.

Edytuj komórkę klikając w nią. Zmiany zapisują się automatycznie. Jak to działa?

Jak to działa

  • Edycja: kliknij w dowolną komórkę, wpisz tekst, Tab/Enter zatwierdza.
  • Współdzielenie: jeśli skonfigurowany jest Firebase (⚙), każda zmiana wszystkich widzą na żywo (1-2s).
  • Bez Firebase: dane trzymają się w localStorage Twojej przeglądarki. Eksport/import JSON żeby się podzielić.
  • Weekendy i święta polskie podświetlone na żółto (na podstawie roku z górnego pola).
  • Reset: ⬆ JSON → wybierz data-initial.json z repo żeby cofnąć do stanu wyjściowego.
